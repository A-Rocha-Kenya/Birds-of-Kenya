# Checklist of the Birds of Kenya v2026.1 — preparation

This draft prepares the next 2026 revision with the September 2026 Kenya EBD (`ebd_KE_smp_relSep-2026.zip`) and AviList v2026. The release is blocked on the official eBird 2026 taxonomy CSV, which is not yet available. There is one eBird taxonomy input, `ebird_taxonomy_path`, targeting `data/ebird/eBird_taxonomy_v2026.csv`.

The names/translations workbook is not used as a replacement taxonomy. The experimental second taxonomy layer, extraction script and alignment step have been removed. Provisional outputs generated through that approach have been moved to ignored local storage; no v2026.1 public assets are staged and no final species count is claimed.

The September EBD contains 4,948,157 observation rows and includes a companion sampling-event file. The archive reader now selects the observation file. The existing Rock Dove and Rose-ringed Parakeet exotic-code corrections are scoped explicitly to September. AviList v2026 column handling and the historical lark crosswalk corrections are retained from the earlier development commit.

The PDF and website retain unresolved Pending EARC flags across release comparisons. CSV exports use the active release ID in their filename. Historical v2026.0 assets are preserved as published at the v2026.0 tag.

Before this PR is ready: obtain the official taxonomy CSV, verify exact concept-ID/category compatibility with the September EBD, review the eBird-to-AviList overrides, rebuild the checklist, and regenerate and validate the comparison, PDFs, GBIF/IPT package and website. If source taxonomy compatibility fails, resolve the source version pairing before proceeding. Update the publication evidence bounds and counts from the accepted build.

Fixture validation covers archive selection, evidence aggregation, taxonomy mapping, comparison behavior, Pending EARC carry-forward and asset staging. Full release, publication and website validation remain pending the missing official source and regenerated assets. Publication, tagging and the GBIF/IPT update remain separate steps.
