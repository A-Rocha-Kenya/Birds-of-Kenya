# Kenya checklist v2019.1 source

`source.pdf` is the original printed 2019 fifth edition, formerly named `2019 Checklist of the Birds of Kenya 5th Edition (2019).pdf`. The maintained `checklist.csv` now uses a single `note` column and omits cross-edition notes and numbering. Values in all retained fields are unchanged from the published v2019.1 CSV. `numbering_crosswalk.csv` preserves its 1996/2009 number references.

The sealed published v2019.1 bundle and GitHub Release retain their original bytes and schema. The new v2019.2 transcription applies the three reviewed Avibase identifier corrections; see `../2019.2/README.md` and `../2019.2/corrections.csv`.
