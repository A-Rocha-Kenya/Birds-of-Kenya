# Kenya checklist v2009.1

This revision assigns Avibase IDs to the 49 previously blank entries in v2009.0. The fourth-edition printed entries, names, status codes, and notes are preserved. The PDF reproduces the 2009 source with the 13 December 2017 corrections.

The assignment table records the printed entry number, selected ID, basis, reason, and Avibase link. Supported assignments have a specific clue from the 2009 account, a separate printed entry that narrows its scope, or an explicit identification in the 2019 account. Interpreted assignments use the corresponding Kenyan account in 2019 and the available historical concepts. The 2009 authors do not establish the full global taxon boundary in those cases.

Run `uv run python scripts/build_legacy_releases.py` to generate the checklist from the sealed v2009.0 CSV and this revision's assignment table.
