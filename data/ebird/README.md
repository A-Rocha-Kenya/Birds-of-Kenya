# Pinned eBird sources

The v2026.1 draft uses the licensed `ebd_KE_smp_relSep-2026.zip` and the official `eBird_Taxonomy_v2026-october-2026.csv`, supplied on 3 November 2026. Configuration has one taxonomy input, `ebird_taxonomy_path`. The original CSV is copied byte-for-byte into `data/ebird/`; its path and SHA-256 are recorded in the release manifest. The integrated eBird–Clements checklist, names workbook, API and older taxonomy files are not release inputs.

The official CSV contains 18,631 taxon concepts. The reader normalizes `bio_concept_code` to the internal `TAXON_CONCEPT_ID` field and uses `sparse_report_as` for parent pointers. The filled `report_as` field includes self-codes and must not be used to infer species parentage for unidentified taxa. Historical uppercase-column CSVs remain readable for earlier releases.

The September EBD contains 4,948,157 observation rows plus a companion sampling-event file. It retains four source concept/category combinations that differ from the official 2026 taxonomy. `data/curation/ebird_taxon_corrections.csv` explicitly scopes their treatment to September: broad Spotted/Mediterranean Flycatcher becomes a slash and remains outside species evidence; the identified striata group becomes Spotted Flycatcher species evidence; old Little Swift joins the new lump; old Rufous-naped Lark receives the documented Kenyan assignment. The latter is a regional interpretation, not global concept equivalence. The original source IDs remain in the compact and release evidence tables, while `audit/ebird_taxon_corrections.csv` records original categories, target IDs/categories, affected row counts and reasons. All unlisted ID/category mismatches still stop the build.

The Rock Dove and Rose-ringed Parakeet exotic-code corrections remain explicitly scoped to September in `data/curation/ebird_exotic_overrides.csv`. Raw observations and the official taxonomy file are never edited.

`derived/` is the checksum-controlled compaction cache. Its metadata covers the EBD, official taxonomy, taxon-correction table, exotic-correction table and compaction schema. Any input change invalidates the cache. The previous names-workbook-derived experiment remains only in ignored `tmp/provisional-taxonomy-workaround/` and is not used for this release.
